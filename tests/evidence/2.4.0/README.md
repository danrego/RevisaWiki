# Evidências da 2.4.0

`evidence_index.json` relaciona os relatórios incorporados, com o caminho de origem, o tamanho e os hashes. Quando um relatório está comprimido, o índice também guarda o hash e o tamanho do conteúdo original. A compressão gzip usa um cabeçalho com data fixa para permitir reprodução exata.

Cada relatório mantém a versão, as fontes e os limites da execução que produziu. A cópia destes arquivos não transforma uma auditoria histórica em revalidação da versão atual. Contagens, falhas, avisos preservados e reaproveitamento de provas precisam ser lidos nos relatórios correspondentes.

As fontes de artigos continuam vinculadas às revisões e hashes dos manifestos. Relatórios de API simulada e testes de navegador local não certificam todos os scripts pessoais de uma sessão real. Nenhuma cópia ou publicação na Wikipédia é feita por este preparador.
